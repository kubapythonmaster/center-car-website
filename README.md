# Center Car - Twoje Centrum Samochodowe

Profesjonalna strona internetowa dla firmy Center Car - serwisu mechanicznego i hurtowni części samochodowych w Warszawie.

## 🚗 O Projekcie

Nowoczesna, responsywna strona internetowa stworzona dla firmy Center Car z Warszawy (Bemowo). Strona prezentuje pełną ofertę usług serwisowych oraz hurtowni części zamiennych.

## ✨ Funkcjonalności

- **Strona główna** - Hero, O nas, Usługi, Części, Flota, Dlaczego my, Kontakt
- **Cennik** - Szczegółowy cennik usług i pakiety przeglądowe
- **Responsywny design** - Działa na wszystkich urządzeniach
- **Modernistyczny design** - Czysty, profesjonalny wygląd bez "AI vibes"
- **React Router** - Płynna nawigacja między stronami
- **Framer Motion** - Subtelne animacje

## 🛠️ Technologie

- **React 18** - Biblioteka UI
- **Vite** - Build tool
- **Tailwind CSS 3** - Stylowanie
- **React Router Dom 7** - Routing
- **Framer Motion 11** - Animacje
- **Lucide React** - Ikony

## 🎨 Kolory Marki

- **Navy**: `#1B3A5F` - Główny kolor
- **Pink**: `#F4C2D7` - Akcent
- **Navy Dark**: `#0F2340` - Ciemniejszy odcień

## 📦 Instalacja

\`\`\`bash
# Instalacja zależności
npm install

# Uruchomienie dev serwera
npm run dev

# Build produkcyjny
npm run build
